06 Set up the invoice desk 20 min · before any real invoice · You

Sign in at /admin/login, then finish Business settings before creating anything.

Nothing legal was pre-filled

GSTIN, PAN, bank details and tax rates are empty by design. Enter them from the actual registration documents.

Required before issuing:

  • GST mode — Unregistered, Regular or Composition. Issuing is blocked until chosen.
  • Name, address, state + state code — decides CGST/SGST vs IGST.
  • GSTIN if registered — format and checksum are validated.
  • Invoice prefix and default due days.
  • Bank / UPI if you want them printed.
Numbering

Allocated at issue, never on drafts, per financial year. Issued invoices are frozen.

E-invoicing is manual

No live IRP connection. Paste IRN and signed QR from the government portal. Confirm with your accountant if it applies.

Two safety nets

Preview: push a branch instead of main for a private URL to review first.

Undo: Vercel → Deployments → last good one → Promote to Production. Seconds, no code changes.

Use Yarn, never plain npm install 
npx --yes yarn@1.22.22 install

Run it locally first

Backend, on an in-memory database so real data is untouchable:

cd "d:\0 My coding projects\suvi-interior\suvi-interior-latest-version-10092026"
$env:PYTHONPATH="$PWD\backend"; $env:MONGO_URL='mongodb://localhost:27017'
$env:DB_NAME='suvi_local'; $env:ADMIN_KEY='<throwaway>'
$env:CORS_ORIGINS='http://localhost:3000'
$env:INVOICE_ADMIN_USERNAME='<local-user>'; $env:INVOICE_ADMIN_PASSWORD='<local-pass>'
$env:INVOICE_ADMIN_COOKIE_SECURE='false'
.\.venv\Scripts\python.exe -u -c "from mongomock_motor import AsyncMongoMockClient; import os, server; server.client.close(); server.client=AsyncMongoMockClient(); server.db=server.client[os.environ['DB_NAME']]; import uvicorn; uvicorn.run(server.app, host='127.0.0.1', port=8001)"
