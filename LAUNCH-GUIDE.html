Create the database

You

MongoDB Atlas free tier. 512 MB, never expires, no card required — far more than this workload needs.

Why allow all IPs?

Vercel runs your API on serverless machines with rotating IP addresses, so there is no fixed IP to allow-list. Access still requires the username and password — that is the actual security boundary.

Your connection string, with the real username filled in. Replace YOUR_NEW_PASSWORD:

mongodb+srv://h000zcom_db_user:YOUR_NEW_PASSWORD@cluster0suvi.j9kb7yi.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0suvi
03

10 minutes

Deploy on Vercel

You

Vercel → Add New → Project → import h000zcom-cloud/main-suvi-interior.

Change the preset before deploying

Your earlier import screen showed Application Preset: FastAPI. That builds only the API and skips the entire website. Set Framework Preset → Other and leave Root Directory as /. The repo's vercel.json builds the site and API together.

Expand Environment Variables and add these five for Production:

KeyValueNotes
MONGO_URLYour string from Step 2Includes the new password
DB_NAMEsuvi_interiorCreated automatically
ADMIN_KEYLong random stringLegacy enquiry key, not your login
INVOICE_ADMIN_USERNAMEe.g. adminYour invoice desk login
INVOICE_ADMIN_PASSWORDStrong passwordSave it — used at Step 6
Leave these unset

REACT_APP_BACKEND_URL, CORS_ORIGINS and INVOICE_ADMIN_COOKIE_SECURE. The site and API share one origin and default to secure HTTPS cookies. Setting a separate API URL would break admin login, because the session cookie is SameSite=Lax and would not be sent cross-site.

The API sleeps when idle, so the very first request after a pause takes a few seconds to wake. This is normal on serverless and only affects the first visitor after a quiet period.

05

15 minutes + DNS propagation

Connect suviinterior.com

You

In Vercel: Project → Settings → Domains → add suviinterior.com, then add www.suviinterior.com and set it to redirect to the apex. Vercel shows the exact DNS records — always trust its panel over any list, including this one.

At your domain registrar (Hostinger if the domain lives there), the records are typically:

TypeNameValue
A@76.76.21.21
CNAMEwwwcname.vercel-dns.com
Remove conflicting records

Delete any existing A or CNAME on @ and www that point to old hosting (parking pages, Hostinger defaults). Leave MX records alone or you will break email. DNS can take up to a few hours to propagate; HTTPS is issued automatically once it resolves.

06

20 minutes · before any real invoice

Set up the invoice desk

You

Go to /admin/login and sign in with the username and password from Step 3. Then open Business settings and complete it before creating anything.

Nothing legal or financial was pre-filled

GSTIN, PAN, bank details, tax rates and prices are all empty by design — inventing them would put wrong numbers on a real tax invoice. Enter them from the client's actual registration documents.

Required before issuing:

  • GST registration mode — Unregistered, Regular or Composition. Issuing is blocked until this is an explicit choice.
  • Business name, address, state and state code — drives whether tax is CGST/SGST or IGST.
  • GSTIN if registered — validated offline for format and checksum, and must match your state code.
  • Invoice prefix and default due days.
  • Bank details / UPI if you want them printed on invoices.
How numbering works

Invoice numbers are allocated only when you issue, never on drafts, and follow the financial year. Issued invoices are frozen: party details, tax and totals cannot be edited afterwards. If settings change a draft's calculation, issuing stops and asks you to review the refreshed draft first.

E-invoicing is manual

There is no live connection to the government IRP. IRN and signed QR fields exist so you can paste values from the official portal. Confirm with your accountant whether e-invoicing applies to this business.

Submit to Google & Bing

You
  1. Verify suviinterior.com in Google Search Console (DNS TXT verification is easiest since you control DNS).
  2. Submit https://suviinterior.com/sitemap.xml.
  3. Repeat in Bing Webmaster Tools — Bing feeds several AI assistants.

09

Ongoing · biggest local lever

Local SEO off the website

You

On-page work is done. Local ranking is now mostly decided outside the website.

1. Google Business Profile

The single highest-impact action. Claim it, use the exact address and phone from the website, primary category Interior designer, secondary Furniture manufacturer. Add real photos monthly.

2. Reviews

Ask after every handover. Reviews that mention the service and area naturally ("modular kitchen in Indira Nagar") help both the map pack and AI answers.

3. Consistent listings

JustDial, Sulekha, IndiaMART, Houzz India, Bing Places, Apple Business Connect. Name, address and phone must match character for character — mismatches suppress ranking.

4. Local links

Builders, architects, suppliers and local press. A few genuine Nashik links beat large numbers of generic directory links.

Your everyday workflow

Shipping design changes safely

Both of us

You said the design needs a lot of changes. This is the loop that keeps production safe while you iterate.

Run it locally first

Two terminals. Backend (in-memory database, so you cannot touch real data):

cd "d:\0 My coding projects\suvi-interior\suvi-interior-latest-version-10092026"
$env:PYTHONPATH="$PWD\backend"; $env:MONGO_URL='mongodb://localhost:27017'
$env:DB_NAME='suvi_local'; $env:ADMIN_KEY='local-only'
$env:CORS_ORIGINS='http://localhost:3000'
$env:INVOICE_ADMIN_USERNAME='demo-admin'; $env:INVOICE_ADMIN_PASSWORD='Suvi-Demo-2026!'
$env:INVOICE_ADMIN_COOKIE_SECURE='false'
.\.venv\Scripts\python.exe -u -c "from mongomock_motor import AsyncMongoMockClient; import os, server; server.client.close(); server.client=AsyncMongoMockClient(); server.db=server.client[os.environ['DB_NAME']]; import uvicorn; uvicorn.run(server.app, host='127.0.0.1', port=8001)"

Frontend:

cd "d:\0 My coding projects\suvi-interior\suvi-interior-latest-version-10092026\frontend"
$env:REACT_APP_BACKEND_URL='http://localhost:8001'
npm.cmd start

Open http://localhost:3000. Edits appear instantly.

If you ever need to reinstall packages

Use Yarn, not npm — this is a Yarn project and plain npm install fails on a peer-dependency conflict and then produces a broken build:

npx --yes yarn@1.22.22 install

Vercel deploys automatically in a couple of minutes.

Safe iteration habits

Preview first: push to a branch instead of main and Vercel gives you a private preview URL to review before it reaches visitors.

Instant undo: Vercel → Deployments → pick the last good one → Promote to Production. Rolls back in seconds without touching code.

Always build before pushing. A local Compiled successfully. is what stops a broken deploy.
